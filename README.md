# Blackbox Viewer

A standalone flight log viewer for **Rotorflight / Betaflight** blackbox logs, built from the latest Betaflight blackbox source. It runs as a **web app** and is also packaged as an **Android app**.

## Features

- Graph-based log playback with zoom, seek, and time controls
- **3D View** — inspect flight orientation in 3D
- **FFT analysis** — vibration spectrum analysis
- Header / field value overlays
- Works entirely offline after load; no FC connection required
